THE CONCEPT

Why do we test in Beta?

In web development, the "Alpha" phase is when the code is first being written and is usually broken. The "Beta" phase means the code is structurally complete and ready for real users to try out.

During Beta, developers rely on testers to click every button, scroll on different phones, and find any visual glitches or broken links so they can be fixed before the final launch.

How to report issues

During a beta test, discovering a bug isn't a failure—it is the entire purpose of the phase.

Found a Bug?

Action Required

If text overlaps, an image fails to load, or an animation stutters, take a screenshot and note what device and browser you are using.
